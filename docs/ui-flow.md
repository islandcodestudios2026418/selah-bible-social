## 設計原則

### 1. 簡化到極致
- 從讀經到發布：最多 3 步
- 經文自動帶入，不用手動複製貼上
- AI 圖卡一鍵生成

### 2. 經文為中心
- 每個領受都連結到具體經文
- 可以看「同一段經文」的所有領受
- 這是與 FB/IG 最大的差異

### 3. 正向的變動獎勵
- 「阿們」取代「讚」— 更屬靈的互動
- 發現不同人對同段經文的領受 — 學習驚喜
- 連續讀經天數 — 成就感

### 4. 有意義的投資
- 領受累積成個人靈修日記
- 社群連結是屬靈夥伴關係
- 時間投入換來的是屬靈成長
